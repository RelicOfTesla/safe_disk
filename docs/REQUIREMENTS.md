# 需求确认

## 项目概述

**Safe Disk** - 跨平台加密目录浏览工具

## 使用场景

**个人使用** - 管理个人的加密文件（文档、图片、笔记等）

## 当前状态

**阶段**: 代码审计进行中，文档中的完成度需要逐条回到实现确认

**代码审计结论**:
- Flutter 主 UI 仍是占位页，不能把“UI 框架完成”直接等同于“功能完成”
- 目录导入/导出在 Dart 侧仍有 `UnimplementedError`
- FFI 有基础绑定，但增量加密 FFI 文档与当前公开导出表不一致
- Go 后端 `sec_fs` 和部分 CLI 能力已存在，但需要按命令逐项确认可用性

**建议参考**:
- 以 [docs/CODE_AUDIT_STATUS.md](CODE_AUDIT_STATUS.md) 作为当前状态的准绳

## 安全威胁模型

### 必须防护 ✅
- ✅ **A. 防窥探** - 防止普通恶意软件/木马读取屏幕内容
  - 实现：记事本必须使用 Flutter 渲染，不能用系统文本框
- ✅ **D. 防文件系统扫描** - 防止木马扫描磁盘上的临时文件/缓存
  - 实现：**不写临时文件到磁盘，所有解密在内存中进行**
  - ⚠️ **严禁解密到 /tmp 等临时目录**
  - ⚠️ **严禁在硬盘里存储明文信息**

### 可选防护 🔸
- 🔸 **B. 防截屏** - 防止木马定时截屏记录
  - 实现：可添加窗口内容保护（但不是 100% 可靠）
- 🔸 **C. 防内存扫描** - 防止木马扫描内存中的明文数据
  - 实现：内存数据用完立即清零（对抗高级木马效果有限）

**影响**：
- 不需要复杂的索引缓存

- 缩略图可以实时生成

## 技术方案

**选择**：FFI + 单体架构

**架构**：Flutter UI ⇄ FFI ⇄ Go 后端（单进程）

**实际实现**：
```
┌─────────────────────────────────────────┐
│   Flutter UI App (lib/)                 │
│  ┌────────────────────────────────────┐ │
│  │ pages/     - UI 页面               │ │
│  │ services/  - 业务服务              │ │
│  │ models/    - 数据模型              │ │
│  │ native/    - FFI 绑定              │ │
│  └────────────────────────────────────┘ │
└─────────────────┬───────────────────────┘
                  │ FFI
┌─────────────────▼───────────────────────┐
│   Go Shared Library (native/)           │
│  ┌────────────────────────────────────┐ │
│  │ cli/        - 命令行工具           │ │
│  │ config/     - 配置解析             │ │
│  │ ffi_sec_fs/ - FFI 导出层           │ │
│  │ sec_fs/     - 核心加密文件系统     │ │
│  │   crypto_data/  - 数据加密算法     │ │
│  │   crypto_hkdf/  - 密钥派生         │ │
│  │   crypto_name/  - 文件名加密       │ │
│  │   sec_transfer/ - 安全传输         │ │
│  └────────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

**理由**：
1. 个人使用，不需要微服务的复杂度
2. 中小规模数据，FFI 性能足够
3. 安全敏感，单进程减少攻击面
4. 部署简单，一个可执行文件搞定

## 非功能需求

### 性能
- 目录扫描：实时扫描，无需索引
- 文件加载：懒加载 + 分页
- 密钥缓存：内存中缓存（支持手动清除）

### 安全
- ⚠️ **严禁解密到 /tmp 等临时目录**
- ⚠️ **严禁在硬盘里存储明文信息**
- ✅ 所有解密在内存中进行
- ✅ 敏感数据用后立即清零
- ✅ 不写临时文件到磁盘
- ✅ 记事本使用 Flutter 渲染
- ✅ 支持嵌套加密目录（独立密钥）

### 用户体验
- 文件打开提示：**"此文件已加密，请在 Safe Disk 中查看"**
- 文件名显示：显示原始文件名（解密后的文件名）
- 导出提示：**"导出解密文件将在硬盘上存储明文，确认继续？"**

### 易用性
- 仿 Windows/Linux 原生文件浏览器
- 密码输入后自动缓存
- 智能加密目录检测（向上查找）
- 右键菜单操作

## 关键设计决策

### 1. 加密目录检测逻辑（类似 .git）
- 从当前目录开始向上查找 `_cryption.json`
- 找到第一个就停止（最近的加密根目录）
- 支持嵌套加密目录，每个有独立密钥

### 2. 密钥管理
- 每个加密目录有独立的密钥
- 密钥缓存以目录路径为键
- 支持手动清除缓存

### 3. FFI 通信
- Go 编译为共享库（.so / .dll）
- Dart 侧负责内存管理
