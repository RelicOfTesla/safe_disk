## 当前执行口径

- Flutter：优先使用可写 SDK 副本 `/tmp/flutter-copy`；真实 FFI 测试通过 `SAFE_DISK_FFI_LIBRARY` 显式指定动态库。
- Go：默认缓存目录在受限环境可能只读；使用 `GOCACHE=/tmp/safe_disk_go_cache` 执行全量 `go test` 与 `go vet`。
- WebDAV HTTP：Flutter widget 测试绑定会拦截 `HttpClient`，因此协议 HTTP 行为由 Go 层真实测试验证；Dart 层以 ABI 静态分析和独立进程验证为准，不能把被拦截的 400 归因于产品。
- 所有新记录必须先判断是否仍是当前有效证据；重复结果只更新基线，不复制整段流水。
