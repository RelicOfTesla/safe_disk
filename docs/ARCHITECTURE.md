# 技术架构

## 整体架构

```
┌─────────────────────────────────────────┐
│   Flutter UI App    │    Go CLI Tool    │
│  ┌──────────────────┼─────────────────┐ │
│  │ 文件浏览│记事本  │  encrypt/decrypt │ │
│  │ 图片浏览器        │  batch operations│ │
│  └──────────────────┼─────────────────┘ │
└─────────────────┬──┴───────────────────┘
                  │ FFI (Flutter) / 直接调用 (CLI)
┌─────────────────▼───────────────────────┐
│           Go Core Library (共享)         │
│  ┌──────────┬──────────┬──────────────┐ │
│  │ 加解密   │ 文件操作 │ 密钥管理     │ │
│  └──────────┴──────────┴──────────────┘ │
└─────────────────────────────────────────┘
```

**架构说明**：
- **Flutter UI App**: 图形界面应用，通过 FFI 调用 Go 库
- **Go CLI Tool**: 独立命令行工具，直接调用 Go 库
- **Go Core Library**: 共享的加密/文件操作库

## Flutter 前端职责

### 1. 文件浏览器界面
- 仿 Windows/Ubuntu 原生文件浏览器
- 目录树导航
- 文件列表视图（图标/列表模式）
- 右键菜单
- 快捷清单侧边栏

### 2. 安全记事本 ⚠️ 关键
- **必须使用 Flutter 渲染文本**，防止被木马元素感知
- 文本编辑器功能
- 部分文本复制
- 自动加密保存

### 3. 图片浏览器
- 支持常见图片格式
- 内存中解密显示
- 基础图片操作（缩放、旋转）

## Go 后端职责

### 1. 加密模块
- AES-256 加密/解密
- 密钥派生（HMAC + IterN）
- 密码校验

### 2. 文件操作
- 加密目录扫描
- 文件加密/解密
- 目录结构映射
- 导出解密文件

### 3. 系统集成
- 剪贴板操作（Windows/Linux）
- 文件拖放
- 右键菜单集成

## 通信方式

**已选择：FFI（推荐）**

**理由**：
- ✅ 低延迟，性能好
- ✅ 部署简单（单可执行文件）
- ✅ 跨平台一致性好
- ✅ Flutter FFI 成熟稳定
- ✅ 个人使用，不需要微服务复杂度
- ✅ 安全敏感，单进程减少攻击面

**实现细节**：
- Go 编译为共享库（.so / .dll）
- Flutter 通过 FFI 调用 Go 函数
- 内存管理：Go 侧分配，Dart 侧释放

## 跨平台策略

### Windows
- 使用 `win32` API 处理剪贴板
- 注册右键菜单
- 文件拖放支持

### Linux
- 使用 GTK 剪贴板 API
- Desktop 文件集成
- 文件管理器扩展

## 性能考虑

1. **密钥缓存**: 内存中缓存 1 小时
2. **懒加载**: 大目录分页加载
3. **异步解密**: 后台线程解密
4. **内存保护**: 敏感数据用后立即清零
