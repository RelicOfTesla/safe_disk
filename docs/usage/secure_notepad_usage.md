# 安全记事本使用说明

> 历史/目标功能说明。当前 Flutter 主 UI 仍需以 [CODE_AUDIT_STATUS.md](../CODE_AUDIT_STATUS.md) 为准，本文不能作为安全记事本已接入当前 UI 的证明。

## 功能概述

安全记事本是 Safe Disk 的核心功能之一，用于在加密目录中安全地编辑文本文件。

## 核心特性

### ✅ 已实现功能

1. **Flutter 渲染文本**
   - 使用 Flutter 的 TextField widget 渲染文本
   - 不依赖系统输入框，防止木马探测
   - 支持桌面端的标准编辑操作（双击、三击、拖拽选择、右键菜单）

2. **基础文本编辑**
   - 支持所有标准文本编辑操作
   - 支持复制、粘贴、剪切
   - 支持部分文本选择和复制

3. **撤销/重做**
   - 支持最多 50 步撤销历史
   - 支持重做被撤销的操作
   - 撤销/重做栈在关闭时会被安全清零

4. **查找/替换**
   - 支持文本查找（F3 或点击查找按钮）
   - 支持单个替换
   - 支持全部替换

5. **自动加密保存**
   - 每 30 秒自动保存一次（如果有更改）
   - 手动保存（Ctrl+S 或点击保存按钮）
   - 保存时自动加密

6. **内存安全**
   - 所有文本数据在内存中处理，不写临时文件
   - 关闭时自动清零内存中的敏感数据
   - 通过 FFI 调用 Go 的 MemZero 函数，确保真正的内存清零

7. **关闭确认**
   - 有未保存更改时，关闭前会提示保存
   - 支持保存、不保存、取消三种操作

### ⚠️ 可选功能（未实现）

1. **行号显示**
   - 当前版本未实现行号显示
   - 可在后续版本中添加

## 使用方法

### 打开文本文件

1. 在文件浏览器中选择一个文本文件
2. 点击"打开"按钮
3. 文件会被解密并在安全记事本中显示

### 编辑文本

1. 直接在文本框中编辑内容
2. 支持所有标准编辑操作
3. 状态栏会显示"未保存"状态

### 撤销/重做

1. **撤销**: 点击工具栏的撤销按钮（或按 Ctrl+Z）
2. **重做**: 点击工具栏的重做按钮（或按 Ctrl+Y）
3. 状态栏会显示当前的撤销/重做栈大小

### 查找/替换

1. 点击工具栏的查找按钮（搜索图标）
2. 在查找框中输入要查找的文本
3. 点击向下箭头查找下一个
4. 在替换框中输入替换文本
5. 点击替换按钮替换单个，或点击全部替换按钮替换所有

### 保存文件

1. **手动保存**: 点击工具栏的保存按钮（或按 Ctrl+S）
2. **自动保存**: 每 30 秒自动保存（如果有更改）
3. 保存时会自动加密

### 关闭记事本

1. 点击窗口的关闭按钮
2. 如果有未保存的更改，会提示保存
3. 选择保存、不保存或取消
4. 关闭时自动清零内存中的敏感数据

## 安全特性

### 防木马探测

- 使用 Flutter 渲染文本，不依赖系统输入框
- 木马无法通过 Hook 系统输入框来窃取内容
- 所有文本渲染都在 Flutter 引擎内部完成

### 内存安全

- 文本数据只存在于内存中，不写临时文件
- 关闭时通过 FFI 调用 Go 的 MemZero 函数清零内存
- 撤销/重做栈也会被安全清零
- 使用 `runtime.KeepAlive` 防止编译器优化掉清零操作

### 自动加密

- 保存时自动使用 AES-256-GCM 加密
- 使用临时密钥 ID（tempKeyID）进行加密
- 密钥在内存中安全存储，有 TTL 限制

## 技术实现

### Flutter 层

> **注意**：Flutter UI 于 2026-04 重构后，`lib/widgets/` 目录已清理。安全记事本功能当前集成在 `lib/pages/home_page.dart` 中，或通过核心服务层调用。

- `lib/pages/home_page.dart`: 主页面（集成安全记事本 UI）
- `lib/native/native_lib.dart`: FFI 调用接口
- `lib/native/bindings.dart`: FFI 绑定定义

### Go 层

- `native/ffi_sec_fs/exports.go`: FFI 导出函数
- `native/sec_fs/internal/utils/memzero.go`: 内存清零实现

### 内存清零流程

1. 用户关闭记事本
2. Flutter 层调用 `_secureClear()` 方法
3. `_secureClear()` 调用 `_clearSecureString()` 清零每个敏感字符串
4. `_clearSecureString()` 通过 FFI 调用 Go 的 `ClearSecureMemory` 函数
5. Go 层调用 `crypto.MemZero()` 清零内存
6. `MemZero()` 使用 `runtime.KeepAlive` 防止编译器优化

## 已知限制

1. **行号显示未实现**: 当前版本不显示行号，可在后续版本中添加
2. **大文件性能**: 对于非常大的文本文件（>10MB），性能可能会下降
3. **UTF-8 编码**: 目前只支持 UTF-8 编码的文本文件
