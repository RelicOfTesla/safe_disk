# 安全记事本使用与实现说明

> 本文描述当前代码，不作为发布级安全认证。总体完成度和剩余缺口见 [代码审计状态](../CODE_AUDIT_STATUS.md) 与 [活跃任务](../TODO.md)。

## 当前能力

- 从已认证的加密根目录打开 `.txt` 和 `.md` 文件。
- 全文编辑、最多 50 个历史状态的撤销/重做。
- 查找下一个、替换当前选区、全部替换。
- 工具栏快速切换只读和编辑模式。
- 手动保存到原文件；按设置的间隔把未提交内容写入同目录的加密草稿。
- 重开时检测安全草稿并询问恢复或放弃；手动保存成功后清理草稿。
- 可显式开启系统剪贴板短文本监视，并快速清空剪贴板。
- 有未保存变更时，关闭前可选择保存、不保存或取消。
- 加载失败可重试；保存失败保留编辑内容和未保存状态，不会自动退出。
- 内容经当前 root session 直接读写，不创建记事本临时明文文件。

当前没有实现行号、语法高亮、编码选择和专用的 Ctrl+S/F3 快捷键。系统或 Flutter 默认文本编辑快捷键不等同于产品已实现这些命令。

## 使用方法

### 打开与编辑

1. 在主界面打开并认证一个加密根目录。
2. 双击或打开 `.txt`、`.md` 文件。
3. 在编辑区修改内容；状态栏会显示字符数、读写模式和保存状态。
4. 使用工具栏的眼睛/编辑图标切换只读与编辑模式。

### 查找与替换

1. 点击工具栏搜索图标展开查找区。
2. 输入查找文本并查找下一个匹配项。
3. 单个替换只作用于当前选中且与查找文本完全一致的内容。
4. “全部替换”修改全部匹配项，并形成可撤销的历史状态。

### 保存与关闭

- 有更改时，工具栏显示保存按钮。
- 安全草稿间隔可在主界面“设置”中选择：关闭、15 秒、30 秒、1 分钟或 5 分钟。
- 定时草稿不会把页面变为“已保存”，也不覆盖原文件。
- 草稿保存失败时保留未保存状态，状态栏显示错误。
- 关闭含未保存内容的页面时，选择“保存”只有在保存成功后才会退出。

## 模块边界

| 模块 | 职责 |
|---|---|
| `lib/widgets/secure_notepad.dart` | 页面导航、关闭确认和错误反馈 |
| `lib/controllers/secure_notepad_controller.dart` | 加载/显式保存、dirty 状态、撤销重做、查找替换、草稿调度和生命周期 |
| `lib/widgets/secure_notepad_sections.dart` | 状态栏、剪贴板监视栏、查找替换栏和编辑器视图 |
| `lib/services/secure_notepad_draft_store.dart` | 同目录内部草稿命名与 root session 加密读写/清理 |
| `lib/services/system_text_clipboard.dart` | 系统短文本剪贴板读取和清空边界 |
| `lib/services/settings_service.dart` | 安全草稿间隔持久化与校验 |
| `lib/services/crypto_service.dart` | rootID session 到加密文件读写的适配 |

记事本只接受已打开 root 的 `tempKeyID`。页面关闭不关闭整个 root session，root session 由主界面目录生命周期管理。

## 安全边界

### 已能从代码和测试确认

- 文件读写经过当前加密 root session。
- 记事本实现没有写临时明文文件的代码路径。
- 草稿位于原文件同一逻辑目录，仅经当前 root session 写入，并从普通文件列表过滤。
- controller 释放时会清空 `TextEditingController` 和历史容器。
- 可控的派生字节副本会调用 FFI secure-memory 清理接口。
- 真实 FFI 测试覆盖中文加密文件名、保存、关闭 root、重新认证和内容重读。

### 不能声称

- Dart VM 的不可变 `String` 无法由应用证明原地清零；清空引用和派生副本不等于 VM 堆中不存在历史副本。
- Flutter 自绘文本不能证明可以防御所有键盘记录、屏幕捕获、输入法、调试器或已控制进程的恶意软件。
- 当前数据算法由 root 配置决定，不能笼统声称记事本固定使用 AES-GCM 或某个固定参数。
- 草稿只能保护最近一次成功草稿写入前的内容；间隔内编辑仍可能在断电时丢失。
- 剪贴板监视会把短文本读入 Dart 内存；关闭监视只停止后续读取，不能证明 VM 历史字符串已原地清零。
