## 技术风险

### 1. Flutter 自定义文本渲染（高风险）
- **风险**: Flutter 文本渲染复杂，可能遇到性能问题
- **缓解**: 调研 `flutter_widget_from_html` 或自定义 `RenderObject`
- **备选**: 使用 Canvas 直接渲染

### 2. FFI 通信复杂度（中风险）✅ 已验证
- **风险**: Flutter FFI 与 Go 交互可能有坑
- **缓解**: 提前验证技术可行性 ✅
- **结果**: FFI 工作正常，应用成功运行

### 3. 跨平台剪贴板（中风险）
- **风险**: Windows/Linux 剪贴板 API 差异大
- **缓解**: 使用成熟库 `github.com/atotto/clipboard`
- **备选**: 限制功能范围

### 4. 性能优化（中风险）
- **风险**: 大文件加密解密可能卡顿
- **缓解**: 异步处理 + 进度显示
- **备选**: 限制单文件大小
