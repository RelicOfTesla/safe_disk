# 常见问题 FAQ

## 1. 为什么在系统文件管理器中打开加密文件是乱码？

**原因**: 加密文件的文件名和内容都经过 AES-256-GCM 加密，系统文件管理器无法识别。

**解决方法**: 
- 在 **Safe Disk 应用** 中打开加密文件
- 或使用 `safe-disk export` 命令导出解密文件

**提示**: Safe Disk 会在加密目录中显示原始文件名（解密后的文件名），方便识别。

---

## 2. 为什么不能解密到 /tmp 目录？

**安全原因**:
- /tmp 目录可能被恶意软件扫描
- 临时文件可能被其他用户访问
- 明文信息存储在硬盘上会增加泄露风险

**Safe Disk 的安全设计**:
- ✅ 所有解密在**内存**中进行
- ✅ **严禁**写临时文件到磁盘
- ✅ 查看文件时直接在内存中解密显示
- ✅ 关闭应用后，内存中的明文数据自动清零

**例外**: 导出解密功能（用户主动选择，会有安全提示）

---

## 3. 如何导出解密文件？

**方法 1: 使用 Flutter 应用**
1. 在 Safe Disk 中右键点击文件
2. 选择“导出解密文件”
3. 阅读明文风险提示并选择“继续导出”
4. 选择目标文件位置

右键菜单会按文件类型显示可执行动作，不会对未知格式显示无效果的“打开”，也不会把目录交给文件删除接口。

其他常用操作包括原子重命名、应用内复制/粘贴、复制名称、复制逻辑路径、查看属性和刷新。名称与逻辑路径是解密后的明文元数据，复制后会进入系统剪贴板；应用内“复制”则只保存逻辑路径和源 session，不产生明文临时文件，可在已解锁 root 之间重新加密。粘贴冲突可取消、保留两者或显式替换。剪切/移动、批量复制和系统文件管理器互通尚未开放。

**方法 2: 使用 CLI 命令**
```bash
safe-disk export -p <password> -s /path/to/encrypted/file.txt -d /path/to/output/file.txt
```

**安全提示**: 导出解密文件会在硬盘上存储明文，请确保目标目录安全。

---

## 4. 如何批量导出解密目录？

**使用 CLI 命令**:
```bash
# 导出整个目录
safe-disk export -p <password> -s /path/to/encrypted/dir -d /path/to/decrypted/dir

# 或使用 find 批量处理
find /encrypted -type f -exec safe-disk export -p "$PASS" -s {} -d /decrypted/{} \;
```

---

## 5. 忘记密码怎么办？

**重要**: 如果忘记密码，无法恢复加密文件！

**原因**: Safe Disk 使用 AES-256-GCM 加密，密码不存储在本地，无法通过其他方式解密。

**建议**:
- 使用密码管理器存储密码
- 创建密码提示
- 定期备份重要文件

---

## 6. 如何修改密码？

**前提**: 只有创建时启用“允许以后修改密码”的目录支持修改密码。Flutter 创建界面默认启用；旧目录、CLI 未显式启用的目录和该选项关闭的目录不支持原地改密。

**方法 1: 使用 Flutter 应用**
1. 在侧边栏右键点击加密目录，选择“修改密码”
2. 输入当前密码、新密码和确认密码
3. 修改成功后用新密码重新解锁

**注意**: 不支持改密的旧格式目录需要新建目录后完整迁移；不要尝试手动编辑 `_cryption.json`。

---

## 7. 可变密码模式和不可变密码模式有什么区别？

| 特性 | 支持改密的新格式 | 旧格式或创建时关闭该选项 |
|------|---------------------|--------------|
| 修改密码 | ✅ 支持 | ❌ 不支持 |
| 本地存储 | 经密码包装的随机内容密钥 | 密码直接派生内容密钥 |
| 安全性 | 依赖强密码、KDF 和已认证的密钥包装 | 依赖强密码和 KDF，不能原地改密 |
| 适用场景 | 需要定期修改密码 | 兼容已有目录或明确不需要改密 |

**推荐**: 新建目录保持“允许以后修改密码”开启；该选项不等同于密码恢复，忘记密码仍无法恢复数据。

## 9. 加密文件可以在其他电脑上打开吗？

**可以**。只要安装 Safe Disk 应用并知道密码，就可以在任何电脑上打开加密文件。

**步骤**:
1. 复制整个加密目录（包括 `_cryption.json`）
2. 在目标电脑上安装 Safe Disk
3. 打开加密目录，输入密码

**不支持**:
- ❌ macOS（暂不支持）
- ❌ 移动端（Android/iOS）

## 11. 如何确保加密文件的安全性？

**Safe Disk 的安全措施**:
1. ✅ AES-256-GCM 强加密算法
2. ✅ 密码和明文密钥不存储在本地；支持改密的目录只保存经密码包装且认证的内容密钥
3. ✅ 所有解密在内存中进行
4. ✅ 不写临时文件到磁盘
5. ✅ 记事本使用 Flutter 渲染，防木马探测
6. ✅ 内存数据用后立即清零

**用户建议**:
1. 使用强密码（至少 12 位，包含大小写字母、数字、符号）
2. 按需要修改支持改密目录的密码，并保管好新密码
3. 不要在公共电脑上保存密码
4. 定期备份加密目录

---

## 12. 加密文件太大，打开很慢怎么办？

**优化方法**:
1. **分批查看**: 不要一次性打开大量文件
2. **使用懒加载**: Safe Disk 支持文件列表懒加载
3. **增加内存**: 大文件解密需要足够的内存

**性能建议**:
- 单个文件建议不超过 100 MB
- 单个目录建议不超过 1000 个文件

---

## 13. 如何备份加密目录？

**方法 1: 直接复制目录**
```bash
cp -r /path/to/encrypted/dir /backup/location/
```

**方法 2: 使用 CLI 命令**
```bash
# 先创建加密目录，再导入文件
safe-disk import -p <password> -s /path/to/plain/dir -d /backup/encrypted/dir
```

**注意**: 备份时记得保存密码！

---

## 14. Safe Disk 会收集用户数据吗？

**不会**。Safe Disk 是本地应用，所有数据都存储在本地，不会上传到云端或发送给第三方。
