# 常见问题 FAQ

## 1. 为什么在系统文件管理器中打开加密文件是乱码？

**原因**: 加密文件的文件名和内容都经过 AES-256-GCM 加密，系统文件管理器无法识别。

**解决方法**: 
- 在 **Safe Disk 应用** 中打开加密文件
- 或使用 `safe-disk export` 命令导出解密文件

**提示**: Safe Disk 会在加密目录中显示原始文件名（解密后的文件名），方便识别。

---

## 2. 为什么不能解密到 /tmp 目录？

**安全原因**:
- /tmp 目录可能被恶意软件扫描
- 临时文件可能被其他用户访问
- 明文信息存储在硬盘上会增加泄露风险

**Safe Disk 的安全设计**:
- ✅ 所有解密在**内存**中进行
- ✅ **严禁**写临时文件到磁盘
- ✅ 查看文件时直接在内存中解密显示
- ✅ 关闭应用后，内存中的明文数据自动清零

**例外**: 导出解密功能（用户主动选择，会有安全提示）

---

## 3. 如何导出解密文件？

**方法 1: 使用 Flutter 应用**
1. 在 Safe Disk 中右键点击文件
2. 选择"导出解密到..."
3. 选择目标目录
4. 确认安全提示

**方法 2: 使用 CLI 命令**
```bash
safe-disk export -p <password> -s /path/to/encrypted/file.txt -d /path/to/output/file.txt
```

**安全提示**: 导出解密文件会在硬盘上存储明文，请确保目标目录安全。

---

## 4. 如何批量导出解密目录？

**使用 CLI 命令**:
```bash
# 导出整个目录
safe-disk export -p <password> -s /path/to/encrypted/dir -d /path/to/decrypted/dir

# 或使用 find 批量处理
find /encrypted -type f -exec safe-disk export -p "$PASS" -s {} -d /decrypted/{} \;
```

---

## 5. 忘记密码怎么办？

**重要**: 如果忘记密码，无法恢复加密文件！

**原因**: Safe Disk 使用 AES-256-GCM 加密，密码不存储在本地，无法通过其他方式解密。

**建议**:
- 使用密码管理器存储密码
- 创建密码提示
- 定期备份重要文件

---

## 6. 如何修改密码？

**前提**: 只有**可变密码模式**（默认）的加密目录支持修改密码。

**方法 1: 使用 Flutter 应用**
1. 打开加密目录
2. 点击"修改密码"
3. 输入旧密码和新密码

**注意**: 不可变密码模式的加密目录不支持修改密码，需要重新加密。

---

## 7. 可变密码模式和不可变密码模式有什么区别？

| 特性 | 可变密码模式（默认） | 不可变密码模式 |
|------|---------------------|--------------|
| 修改密码 | ✅ 支持 | ❌ 不支持 |
| 本地存储 | 加密后的文件密钥 | 无任何密钥 |
| 安全性 | 高 | 最高 |
| 适用场景 | 需要定期修改密码 | 极度安全需求 |

**推荐**: 大多数用户使用可变密码模式（默认）即可。

---

## 8. 如何查看加密目录的信息？

**使用 CLI 命令**:
```bash
safe-disk list -p <password> -d /path/to/encrypted/dir

# 输出示例

=====================================
[DIR ] documents (0 bytes)
[FILE] readme.txt (1245 bytes)
=====================================
Total: 2 items
```

## 9. 加密文件可以在其他电脑上打开吗？

**可以**。只要安装 Safe Disk 应用并知道密码，就可以在任何电脑上打开加密文件。

**步骤**:
1. 复制整个加密目录（包括 `_cryption.json`）
2. 在目标电脑上安装 Safe Disk
3. 打开加密目录，输入密码

---

## 10. Safe Disk 支持哪些操作系统？

**支持平台**:
- ✅ Windows 10/11
- ✅ Linux (Ubuntu 20.04+, Debian 11+)

**不支持**:
- ❌ macOS（暂不支持）
- ❌ 移动端（Android/iOS）

---

## 11. 如何确保加密文件的安全性？

**Safe Disk 的安全措施**:
1. ✅ AES-256-GCM 强加密算法
2. ✅ 密钥不存储在本地
3. ✅ 所有解密在内存中进行
4. ✅ 不写临时文件到磁盘
5. ✅ 记事本使用 Flutter 渲染，防木马探测
6. ✅ 内存数据用后立即清零

**用户建议**:
1. 使用强密码（至少 12 位，包含大小写字母、数字、符号）
2. 定期修改密码（可变密码模式）
3. 不要在公共电脑上保存密码
4. 定期备份加密目录

---

## 12. 加密文件太大，打开很慢怎么办？

**优化方法**:
1. **分批查看**: 不要一次性打开大量文件
2. **使用懒加载**: Safe Disk 支持文件列表懒加载
3. **增加内存**: 大文件解密需要足够的内存

**性能建议**:
- 单个文件建议不超过 100 MB
- 单个目录建议不超过 1000 个文件

---

## 13. 如何备份加密目录？

**方法 1: 直接复制目录**
```bash
cp -r /path/to/encrypted/dir /backup/location/
```

**方法 2: 使用 CLI 命令**
```bash
# 先创建加密目录，再导入文件
safe-disk import -p <password> -s /path/to/plain/dir -d /backup/encrypted/dir
```

**注意**: 备份时记得保存密码！

---

## 14. Safe Disk 会收集用户数据吗？

**不会**。Safe Disk 是本地应用，所有数据都存储在本地，不会上传到云端或发送给第三方。
