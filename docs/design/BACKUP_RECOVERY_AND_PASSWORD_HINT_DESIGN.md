# 加密目录备份、恢复与密码提示设计

> 状态：仅完成设计。当前没有备份格式、恢复入口、密码提示字段或密码找回能力；本文不表示这些功能已经可用。

## 1. 不可改变的安全事实

- 忘记密码时，Safe Disk 不能恢复文件，也不能重置密码。密码提示不是恢复材料，不能降低这一限制。
- 备份保存的是加密目录快照，不导出明文，也不把密码、派生密钥、内容密钥或会话 token 写入备份。
- 任何恢复都必须使用原目录密码验证；“能看到备份”不等于“能读取内容”。
- 备份不是同步、版本历史或云服务。首版不联网、不上传、不自动清理旧备份。

## 2. 密码提示

### 威胁模型

目录配置在磁盘上可被复制、删除或替换。因此提示内容不能被视为秘密，也不能包含密码、密码片段、助记词、私钥或可直接缩小密码空间的信息。

### 格式

- 新建 root 可选保存 `sec_password_hint`，UTF-8 最多 256 字节，允许为空表示不保存。
- 提示与 root 配置一起保存，受现有配置写入/替换流程保护；它不作为密码验证或密钥派生输入。
- 读取配置即可显示提示，输入密码前也可以显示；UI 必须在提示旁固定说明“提示会显示给能访问此目录的人”。
- 改密不会自动改提示。改密成功后提示保留，但属性/改密完成页应提示用户复核是否仍适用。
- 旧 root 没有字段时显示“未设置提示”，不迁移、不伪造默认提示。

### UI

1. 创建目录的高级安全选项中提供可选多行“密码提示”。
2. 解锁页只有在配置含非空提示时显示，默认折叠为“显示密码提示”，避免肩窥时主动暴露。
3. root 属性页可查看和清除提示；修改提示需要已解锁会话和当前密码确认，复用配置锁与 staged replace，不借用改密 API。
4. 输入框附近不使用“找回密码”“恢复密码”等措辞，只写“帮助回忆密码”。

## 3. 备份与恢复

### 首版备份语义

- 备份对象是整个加密 root 的可信快照，包括配置和密文 backing store；不对内部文件逐项导出明文。
- 必须由 sec 层在无活动 Transfer、无未完成 convert、无 active root 写入时创建。UI 只发起请求和展示结果。
- 备份目标只能是不存在的目录，或用户明确选择的空目录；绝不合并到已有目录。
- 快照使用临时目录、fsync/rename 与 manifest。manifest 至少记录格式版本、源 root 标识、创建时间、文件清单摘要和认证完整性信息；不记录密码或明文路径。
- 备份完成后显示目标绝对路径和“仍需记住原密码”。

### 首版恢复语义

- 恢复只写入不存在或空的目标目录，默认拒绝覆盖。
- 先校验 manifest/完整性，再复制密文快照；恢复后必须用用户输入密码打开 root 并列出配置，才报告成功。
- 目标已经是 root、存在 unfinished 状态、或恢复验证失败时保留恢复工作目录供诊断，不替换任何已有 root。
- 恢复不重置密码、不更改提示、不把备份转为可改密码格式。

## 4. 需要的分层接口

```text
Flutter 设置/侧边栏操作
  -> BackupRecoveryService（确认、目标选择、进度、错误分层）
  -> Dart FFI
  -> sec_fs SnapshotBackup / RestoreSnapshot
```

- UI 不遍历 backing store，也不直接使用 `Directory.copy` 伪造一致性快照。
- sec API 需要返回结构化阶段：验证源、复制、同步、验证备份、恢复验证；可取消阶段和不可取消提交阶段必须区分。
- 同一 root 使用现有私有缓存操作锁，与 import/export/convert 串行。
- 密码提示配置更新使用与改密相同的 root 配置跨进程锁和 staged replace，但单独定义 FFI，避免扩大改密调用语义。

## 5. 验收

自动化：

- 空/正常/过长/非 UTF-8 提示；提示不影响错误密码拒绝、派生和改密。
- 提示写入的 staged replace 失败时正式配置不变；跨进程锁竞争与取消。
- 备份/恢复普通 root、加密名称 root、可改密码 root；恢复后旧/新密码行为保持。
- 目标非空拒绝、manifest 篡改拒绝、复制中断不覆盖目标、备份与 Transfer 锁冲突。
- FFI/Dart/widget 覆盖折叠提示、肩窥默认、覆盖确认、错误/取消、成功后的重新解锁。

桌面实测：

- Linux/Windows/macOS：长路径、权限拒绝、断电/kill、占用句柄和移动介质断开。
- 三平台：提示不自动暴露、不写入日志；备份中没有明文、密码或 session token；恢复不覆盖已有 root。
